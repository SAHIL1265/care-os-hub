# CareOS AI: Your Health Partner

Build a production-quality web application called "CareOS AI" – an AI-Powered Healthcare Operating System for Families, Patients, Caregivers, Doctors, and Hospitals.

The application should have a premium UI inspired by Apple Health, Google Fit, Notion, Stripe Dashboard, and Linear.

Use:
- React
- TypeScript
- Tailwind CSS
- Shadcn UI
- Framer Motion animations
- Lucide Icons
- Responsive Design
- Glassmorphism
- Soft Blue (#2563EB) and Emerald Green (#10B981)
- Dark and Light Mode
- Modern dashboard layout
- Accessibility-first design

The application should look like a startup product ready for production, not a student project.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
